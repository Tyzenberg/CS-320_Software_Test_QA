# CS-320_Software_Test_QA
Project for SNHU CS-320 Software Test Automation QA

How can I ensure that my code, program, or software is functional and secure?
I can ensure it is functional and secure with proper testing.

How do I interpret user needs and incorporate them into a program?
If I turn user needs into system requirements, I can then build tests to match the requirements, ensuring I am meeting customer needs.

How do I approach designing software?
Using Test Driven Development, before any code is written, I start to write tests that meet the requirements. When all of the tests are written, I can then start writing code that will pass all tests.
